# 📈 AI-Stock-Advisor-CrewAI

AI-Stock-Advisor-CrewAI is an agent-based AI application that provides current stock insights using real-time market data.
The system uses CrewAI agents to fetch, analyze, and summarize stock information through a Streamlit interface.

# ✨ Features

🤖 Agent-based stock analysis using CrewAI

📊 Real-time stock data via Yahoo Finance

🧠 LLM-powered market insights

⚡ Interactive Streamlit UI

☁️ Deployed as a web application

# 🛠 Tech Stack

1. Agent Framework: CrewAI

2. LLM Provider: Groq

3. Market Data: Yahoo Finance (yfinance)

4. UI: Streamlit

5. Language: Python

# 📦 Dependencies

crewai

crewai-tools

python-dotenv

yfinance

litellm

streamlit

# 🧠 How It Works

- User enters a stock symbol

- CrewAI agents retrieve live market data

- Agents analyze trends and metrics

- Groq LLM generates a clear summary

- Results are displayed in the Streamlit UI

# 🚀 Run Locally

1. pip install -r requirements.txt


2. Create a .env file:

GROQ_API_KEY=your_api_key_here


3. Run the app:

streamlit run app.py


4. Open:
👉 http://localhost:8501
